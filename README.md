# Web Programming Lab 1 - HTML Basics

My first HTML exercises for learning how a web page is structured.

## What I practiced
- HTML headings, paragraphs and line breaks
- Bold, italics, underlining and other text formatting
- Subscript and superscript
- HTML entities and description lists
- Basic page structure with `head` and `body`

## Files
- `myfirstpage.html` - first HTML page
- `Entities.html` - HTML entity practice

## How to view
Download the files and double-click either `.html` file to open it in a browser. No server or installation is needed.

These are early course exercises and intentionally use some older HTML formatting elements. In modern websites, CSS is preferred for styling.
